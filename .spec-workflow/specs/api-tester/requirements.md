# Requirements: API Tester

## 状态
- **状态**：草稿 Draft
- **创建日期**：2026-05-12
- **来源需求**：开发与测试人员需要一个轻量、无需安装的静态网页工具，用于快速调试和验证 HTTP 接口

---

## 1. 背景与目标

### 1.1 背景
在日常接口开发与联调过程中，团队需要频繁地发送 HTTP 请求验证接口行为。现有的桌面工具（如 Postman）需要安装客户端，部署成本较高。为降低使用门槛，计划提供一款纯静态网页版 API 测试工具，无需后端服务、无需安装，打开浏览器即可使用。

### 1.2 目标
- 提供基础的 HTTP 请求发送能力（GET / POST）
- 支持自定义请求 Header 和 Body
- 以可读方式展示响应结果（JSON 高亮格式化）
- 展示响应状态码与请求耗时，辅助判断接口状态

### 1.3 非目标（本期不做）
- 不支持请求历史记录与本地持久化存储
- 不支持多 Tab 并行请求
- 不支持环境变量与全局变量配置
- 不支持断言/自动化校验
- 不提供 CORS 跨域代理（用户需自行配置服务器 CORS 或使用浏览器插件解决跨域限制）
- 不支持 PUT / DELETE / PATCH 等其他 HTTP 方法（基础版范围）

## 2. 用户故事

### US-001：发送 GET 请求并查看响应
**作为** 后端开发工程师，  
**我希望** 在网页中输入接口 URL 并选择 GET 方法后点击发送，  
**以便** 快速验证 GET 接口是否正常返回预期数据。

**验收标准：**
- [ ] 用户可在输入框中输入合法的 HTTP/HTTPS URL
- [ ] 选择 GET 方法后点击"发送"按钮可触发请求
- [ ] 请求完成后，响应内容显示在页面响应区域
- [ ] 若 URL 为空，阻断请求并提示"请输入请求地址"
- [ ] 若 URL 格式非法，阻断请求并提示"URL 格式不正确"

---

### US-002：发送 POST 请求（含 Header / Body 配置）
**作为** 后端开发工程师，  
**我希望** 配置请求 Header 和 JSON Body 后发送 POST 请求，  
**以便** 验证需要提交数据的接口行为是否正确。

**验收标准：**
- [ ] 用户可添加、编辑、删除 Header 键值对（Key-Value 形式）
- [ ] 用户可在 Body 输入区域输入 JSON 文本或 Form 表单数据
- [ ] 选择 POST 方法后，Body 输入区域可用
- [ ] 选择 GET 方法后，Body 输入区域禁用或隐藏
- [ ] Body 内容为空时，POST 请求仍可发送（允许无 Body 的 POST）
- [ ] Body 为 JSON 格式时，自动添加 `Content-Type: application/json` Header（可被用户覆盖）

---

### US-003：响应内容 JSON 高亮格式化展示
**作为** 测试工程师，  
**我希望** 响应内容以高亮、缩进格式化的 JSON 方式展示，  
**以便** 快速定位和阅读接口返回的字段结构。

**验收标准：**
- [ ] 当响应 Content-Type 为 `application/json` 时，自动格式化并高亮展示
- [ ] JSON 高亮区分字符串（字符串色）、数字（数字色）、布尔值（布尔色）、null（空值色）、键名（键名色）
- [ ] 当响应内容不是合法 JSON 时，以原始文本形式展示，不报错
- [ ] 响应区域支持纵向滚动，不截断长内容

---

### US-004：查看响应状态码与请求耗时
**作为** 开发工程师，  
**我希望** 发送请求后能立即看到 HTTP 状态码和本次请求耗时，  
**以便** 快速判断接口是否正常以及响应性能。

**验收标准：**
- [ ] 响应区域顶部显示 HTTP 状态码（如 `200 OK`、`404 Not Found`）
- [ ] 状态码 2xx 显示绿色标识，4xx 显示橙色标识，5xx 显示红色标识
- [ ] 显示本次请求耗时（单位：ms），精确到毫秒
- [ ] 请求发送中显示加载状态（Loading 指示器）
- [ ] 请求超时或网络错误时，响应区域显示错误信息，不崩溃页面

## 4. 非功能需求

| 类型 | 要求 |
|---|---|
| 部署方式 | 纯静态单页应用（HTML + CSS + JS），无需服务器，可直接通过浏览器打开文件或部署至静态托管服务 |
| 兼容性 | 支持 Chrome、Edge 最新两个主版本 |
| 跨域限制 | 不内置跨域代理，受浏览器同源策略限制；文档中需说明用户可通过配置服务器 CORS 或安装浏览器插件解决 |
| 性能 | 页面首次加载时间 ≤ 2s（本地文件打开场景） |
| 可访问性 | 关键操作元素需有清晰的标签和状态反馈 |
| 安全 | 不存储任何用户输入数据，不向第三方发送请求数据 |

## 5. 开放问题
