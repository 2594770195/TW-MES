# Requirements: 成品工单半成品批次分配

## 状态
- **状态**：草稿 Draft
- **创建日期**：2026-07-06
- **范围**：新增 SQL Server 表结构与存储过程，用于记录成品工单对应的半成品批次预分配
- **目标对象**：`MO`、`MOItem`、`WW_RMInventory` 与新增分配记录表

---

## 1. 背景与目标

### 1.1 背景
成品工单投产前，需要提前指定可用于该工单的半成品批次。当前库存表 `WW_RMInventory` 记录批次库存，但没有独立记录“某个成品工单已预分配哪些半成品批次”的台账，业务人员无法清晰查看需求数量、已分配数量、批次可用库存和已分配批次。

### 1.2 目标
- 根据成品工单号查询该工单需要的半成品物料、所需数量、已分配数量和剩余数量。
- 根据半成品 `ProductId` 查询可分配批次库存，展示库存、可用库存、已分配库存及库存相关信息。
- 查询当前成品工单已分配的半成品批次及相关信息。
- 输入批次号 `LotSN`，自动按“剩余需求量”和“批次可用量”的较小值分配给当前工单。
- 输入分配记录表 ID，删除该行分配记录。
- 分配记录需保留历史；实际领料与预分配不一致时，通过表内占用标记控制该记录是否继续占用已分配数量。

### 1.3 非目标
- 不直接修改 `WW_RMInventory.Qty`。
- 不直接修改 `WW_RMInventory.LotStatus`。
- 不直接修改 `MOItem.ItemQtyIssued`、`ItemQtyDone` 等正式领料字段。
- 不改造现有领料、调拨、WMS 同步流程。
- 不做前端页面和后端 API，本期只提供数据库对象。

---

## 2. 功能需求

### F-001 查询工单半成品物料需求
输入工单号或工单 ID，查询当前工单需要的半成品物料信息。

验收标准：
- [ ] 只查询 `MOItem` 中未删除、`LineSequence<>'000'` 的物料行。
- [ ] 只查询 `Product.ProductClassify='2'` 的半成品物料。
- [ ] 返回工单、工单物料行、物料名称、描述、所需数量、已分配数量、剩余数量、单位等信息。
- [ ] 已分配数量只统计新增分配记录表中未删除且占用标记为占用的记录。


### F-002 查询半成品可分配库存
输入 `ProductId`，查询该半成品当前可分配批次库存。

验收标准：
- [ ] 库存来源为 `WW_RMInventory`。
- [ ] 只查询 `LotStatus='1'`、`IsStorage=1`、`Qty>0` 的库存。
- [ ] 已分配库存为新增分配记录表中同 `LotSN` 未删除且占用标记为占用的记录数量汇总。
- [ ] 可用库存 = `WW_RMInventory.Qty - 已分配库存`。
- [ ] 只返回可用库存大于 `0` 的批次。
- [ ] `LotSN` 在 `WW_RMInventory` 中默认唯一；若库存表同一 `LotSN` 存在多行在库记录，视为异常数据，不参与可分配库存查询。
- [ ] 返回 `LotSN`、`ProductionLotNO`、工厂、仓库、储位、库存数量、已分配库存、可用库存、生产日期、有效期等信息。

### F-003 查询当前工单已分配批次
输入工单号或工单 ID，查询当前工单已分配的半成品批次。

验收标准：
- [ ] 只返回新增分配记录表中未删除记录。
- [ ] 返回分配记录 ID、工单、工单物料行、物料、批次、分配数量、是否占用已分配数量、库存位置、创建人、创建时间等信息。

### F-004 输入 LotSN 自动分配批次
输入当前工单物料行与 `LotSN`，系统自动计算分配数量并插入记录表。

验收标准：
- [ ] 校验工单物料行存在且为半成品。
- [ ] 校验批次存在、在库、状态正常、数量大于 `0`。
- [ ] 校验批次物料与工单物料一致。
- [ ] 重新计算当前工单物料剩余需求量。
- [ ] 重新计算当前批次可用库存。
- [ ] 分配数量 = `MIN(剩余需求量, 批次可用库存)`。
- [ ] 剩余需求量或批次可用库存小于等于 `0` 时阻断并返回可理解提示。
- [ ] 插入记录使用事务，避免重复点击导致超分配。

### F-006 按入库时间 FIFO 自动分配（AutoAssign）
输入当前工单物料行 `@MOItemId`，按库存 `EntryDate` 先进先出自动填满剩余需求。

验收标准：
- [ ] 校验工单物料行存在且为半成品。
- [ ] 库存过滤口径与 `GetInventory` 一致（在库、状态正常、LotSN 唯一、可用量 > 0）。
- [ ] 按 `EntryDate`、`LotSN` 升序逐批分配。
- [ ] 每批分配数量 = `MIN(剩余需求量, 批次可用库存)`，循环至需求满足或库存用尽。
- [ ] 无剩余需求或无可分配库存时阻断并返回提示。
- [ ] 库存不足时允许部分分配，返回本次分配批次数、分配数量、剩余未分配数量。
- [ ] 整段写入使用事务。

### F-005 输入记录 ID 删除分配记录
输入分配记录表 ID，删除对应分配记录。

验收标准：
- [ ] 采用逻辑删除，不物理删除。
- [ ] 删除后该记录不再参与已分配数量、已分配库存和已分配批次查询。
- [ ] 删除不存在或已删除的记录时返回业务提示。

## 3. 输入参数

存储过程通过 `@I_Sender` 区分功能，保留 OrBit DoMethod 标准参数，并增加业务参数。

| 参数 | 用途 |
|---|---|
| `@I_Sender` | 功能分支：`GetMOProduct` / `GetInventory` / `GetAllocatedLots` / `AssignLot` / `AutoAssign` / `DeleteLot` |
| `@MOId` | 工单 ID |
| `@MOName` | 工单号 |
| `@MOItemId` | 工单物料行 ID（`AutoAssign` 必填） |
| `@ProductId` | 半成品物料 ID |
| `@LotSN` | 库存批次号 |
| `@MOSemiFinishedLotAllocationId` | 分配记录 ID |

---

## 4. 数据口径

- 半成品范围：`Product.ProductClassify='2'`。
- 有效工单物料行：`MOItem.LineSequence<>'000'` 且 `ISNULL(MOItem.DeleteFlag,'') IN ('','0')`。
- 有效库存：`WW_RMInventory.LotStatus='1' AND WW_RMInventory.IsStorage=1 AND WW_RMInventory.Qty>0`。
- 分配记录表：新增 `MOSemiFinishedLotAllocation`，避开已存在的 `MOProductionLot`。
- 分配记录删除标记：`DeleteFlag='0'` 表示有效，`DeleteFlag='1'` 表示已删除。
- 有效分配记录：`MOSemiFinishedLotAllocation.DeleteFlag='0'`。
- 占用分配记录：有效分配记录且 `IsOccupyAllocatedQty=1`。
- 已分配数量：按 `MOId + MOItemId + ProductId` 汇总占用分配记录 `Qty`。
- 已分配库存：按 `LotSN` 汇总占用分配记录 `Qty`；`WW_RMInventory` 同一 `LotSN` 多行在库记录视为异常。
- 已分配批次查询：默认返回有效分配记录，并展示 `IsOccupyAllocatedQty`，便于区分“保留历史但不再占用”的记录。

---

## 5. 风险与控制

- 防止超分配：写入前在事务内重新计算剩余需求和批次可用库存。
- 防止影响正式库存：不修改库存数量和库存状态，只维护预分配台账。
- 防止字段猜测：实现前必须以 `MES/table/` 表结构为准。
- 防止旧流程冲突：`MOProductionLot` 已存在或被历史流程引用，本期改用 `MOSemiFinishedLotAllocation` 作为独立预分配记录表。

## 6. PDA 成品灌墨消费规则

### F-007 扫描指定批次
- 成品灌墨扫描半成品批次时，不再以 `PickingListItemLot` 是否已领料作为准入条件。
- 扫描批次必须存在当前工单、工单物料、批次号一致，且 `DeleteFlag='0' AND IsOccupyAllocatedQty=1` 的预分配记录。
- 当前批次可用数量 = 当前工单物料和批次的占用分配数量 - 当前 `LoadingItemLot` 已使用数量。
- 实际使用数量不得超过当前批次可用数量，也不得超过当前工单物料的剩余需求。

### F-008 扫描数量确认
- 当扫描批次可用数量大于当前工单物料剩余需求时，扫描事件仅返回剩余需求数量，不写入上料、投料和数据链记录。
- PDA 在 `InputNumberDefocus` 事件确认数量；确认数量合法后才写入 `LoadingItemLotRecord`、投料明细和数据链。
- 当批次可用数量小于或等于剩余需求时，沿用现有扫描即按可用数量写入的行为。

### F-009 完工领料与预分配释放
- 自动完工和手工批次下线前，按当前 `LoadingItemLot` 中 `IsPicking=0` 的实际使用记录生成生产领料单。
- 领料单生成范围仅限当前上料会话，不处理其他会话的未领料记录。
- 完工、过站和报工成功后，将当前会话实际使用批次对应的有效预分配记录更新为 `IsOccupyAllocatedQty=0`，并更新 `ModifyDate`。
- 释放预分配保留历史记录，不逻辑删除；未实际使用的预分配记录继续占用数量。

> PDA 灌墨消费的完整需求、设计与任务见独立规格：`.spec-workflow/specs/finished-ink-allocation-picking/`。
